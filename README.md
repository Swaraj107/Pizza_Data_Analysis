# Pizza Sales Analytics Dashboard

## Project Summary

This project analyzes pizza sales performance using SQL and Microsoft Excel to uncover key business insights related to revenue, order behavior, product performance, peak demand periods, and customer purchasing patterns.

The final deliverable is an interactive Excel dashboard supported by SQL analysis for KPI calculation, sales trends, category performance, size performance, and best/worst-selling pizzas.


## Business Problem

A pizza business needs to understand sales performance across products, time periods, categories, and pizza sizes in order to improve revenue, optimize inventory, plan staffing, and identify menu improvement opportunities.

This project converts raw sales data into clear business insights that can support operational, sales, and marketing decisions.

## Project Objective

- Analyze overall sales performance using key business KPIs
- Identify peak order days and time windows
- Determine the best-performing pizza categories and sizes
- Find top-selling and low-performing pizzas
- Build a clean Excel dashboard for business users
- Use SQL queries to validate KPIs and generate analytical insights

## Dataset Overview

The dataset contains pizza sales transaction data, including order details, pizza names, pizza categories, pizza sizes, quantities sold, order dates, order times, and sales amounts.

The raw data is stored inside the Excel workbook and can also be exported to `data/pizza_sales_raw_data.csv` for easier inspection and reuse.

## Project Insights

- Total revenue reached **$817,860**, showing strong overall sales volume.
- The business processed **21,350 orders** and sold **49,574 pizzas**.
- The average order value was **$38.31**, with an average of **2.32 pizzas per order**.
- **Friday and Saturday** were the busiest order days, indicating strong weekend demand.
- Peak demand occurred during lunch and dinner windows, especially around **12 PM to 1 PM** and **5 PM to 8 PM**.
- The **Classic** category contributed the highest sales share.
- **Large** pizzas generated the highest revenue contribution among pizza sizes.
- **Classic Deluxe Pizza** and **Barbecue Chicken Pizza** were among the strongest-performing products.
- **Brie Carre Pizza** was one of the weakest performers and may require promotion, repositioning, or removal analysis.
- Customer demand is highly time-dependent, which can support better staffing, kitchen planning, and inventory control.

## Business Recommendations

- Increase staffing and kitchen preparation during Friday and Saturday evening peak hours.
- Maintain higher inventory levels for popular pizza categories and large-size pizzas.
- Use peak-hour demand patterns to improve kitchen workflow and reduce order delays.
- Bundle best-selling pizzas with beverages or sides to increase average order value.
- Run targeted promotions for low-performing pizzas to test whether demand can be improved.
- Review underperforming pizzas before removing them from the menu.
- Use category and size-level insights to improve menu design and pricing strategy.
